# IronCore

В разработке

**IronCore** — экспериментальный open-source прототип сетевого тактического танкового экшена, написанный на чистом **C (C17)** с упором на минимализм, высокую производительность и честную серверную физику.

Проект разрабатывается как учебный и исследовательский пет-проект с открытой архитектурой.

---

## Игровая концепция

* **Одна машина на старте:** Игрок начинает путь с одной базовой единицей бронетехники.
* **Модульная прокачка:** За боевые достижения (уничтожение противников, помощь союзникам, разведка) начисляются очки достижений. За них приобретаются и устанавливаются новые модули (орудия, двигатели, броня, приборы наблюдения).
* **Экономика техники:** Собранную машину можно продать другому игроку за очки достижений или сдать в утиль для возврата части ресурсов.
* **Бессмертный экипаж:** Техника может быть уничтожена или продана, но экипаж остается с игроком навсегда. Вместо привязки к штатной численности конкретных танков экипаж представлен единым профилем навыков (командир, механик, наводчик и др.), которые прокачиваются в боях.
* **Ответственность в бою:** За нанесение урона союзникам (friendly fire) экипаж теряет накопленный опыт.

## Технический стек и архитектура

Проект разделен на три независимых модуля:
* `common/` — общий бинарный сетевой протокол (`protocol.h`), общие математические структуры и константы.
* `server/` — авторитарный выделенный сервер (тестируется на **Raspberry Pi 4B, ARM64, Debian 13**).
* `client/` — игровой клиент (разрабатывается на **x86_64, Ubuntu 26.04**).

### Зависимости
* **Компилятор:** `clang` (стандарт `-std=c17`)
* **Сборка:** `GNU Make`
* **Сеть:** `libenet` (надежный и ненадежный UDP поверх единого сокета)

## Сборка и запуск (текущий этап: сетевой скелет)

### 1. Установка зависимостей (Debian / Ubuntu)
```bash
sudo apt update
sudo apt install -y clang libenet-dev pkg-config make
```

### 2. Сборка сервера
```bash
cd server
make
./ironcore_server
```

### 3. Сборка клиента
```bash
cd client
make
./ironcore_client 192.168.0.150
```
